# Bolo 0.1.12

Urdu and Hindi can stay in their own script, and a second set of test sentences can be scored by language.

## Dictation

- Hindi stays in Devanagari when you set I speak to Hindi and keep the language you spoke. Urdu still stays in Urdu script.
- If the online speech service is down, an English-only offline model is not used for Urdu, Hindi, or mixed speech. You can download a multilingual model, about 148 MB or 488 MB. The file is checked before it is saved.

## Accuracy

- Settings can record a second set of sentences: everyday Urdu, mixed Urdu and English, Hindi, and English names, numbers, and emails. The original 30 sentences are unchanged.
- The score shows the average word error for English, Urdu, mixed, and Hindi, and whether the first or last word was dropped.

## Site

- A missing page stays a missing page. It is not replaced by the homepage. The contact page still opens.
- The README points at this version, the site, and the Microsoft Store.
