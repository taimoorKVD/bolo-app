# Bolo 0.1.19

Words show up in the overlay while you dictate, and a cleanup problem no longer hides what Groq actually said.

## What's new

- Live words appear as you speak, for Bolo Blob, Mic Buddy, Glow Spirit, Pebble, and Classic.
- If Groq blocks a cleanup model, Bolo tries the next one and writes the provider status into the log. The API key is never logged.
- Fix last stays quiet when your words were inserted and only the cleanup rewrite fell back. It still appears when the inserted text itself looks doubtful.
