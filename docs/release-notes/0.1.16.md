# Bolo 0.1.16

On-device dictation no longer pastes a program warning, and a failed online request records the real reason.

## Dictation

- Bolo uses whisper-cli, not the old main.exe stub. A deprecation warning is never inserted.
- If the online service rejects a take, the log shows the HTTP status or that the built-in key is missing. The key itself is not written. A key that was marked unusable is tried again on the next take.
- A transcript that already came back is still inserted. If a take really cannot be transcribed, Bolo says "Couldn't catch that, please try again."
