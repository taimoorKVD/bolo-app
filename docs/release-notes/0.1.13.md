# Bolo 0.1.13

The test-sentence recorder uses the microphone that is already open, and Stop saves the take.

## Accuracy

- Record and Stop use the same microphone as dictation. A second microphone is not opened.
- Stop writes the audio, the sentence, and the language tag on this PC immediately. Leaving the page still saves an open take.
- Start, stop, save, and errors are written to bolo.log, and an error is shown in Settings.

## Settings

- A change is saved when the window closes, not only after a short wait.
