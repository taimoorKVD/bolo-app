# Bolo 0.1.20

Accuracy fixes found in the 0.1.19 logs.

## What's new

- Auto language now means English + Urdu. When Whisper guesses another language (French, Spanish), Bolo always keeps the English or Urdu re-listen instead of translating the audio. 0.1.19 pasted "Bye." for a take it heard as French.
- Bolo keeps listening about half a second after you let go of the key, so the last word is no longer cut off.
- New words are learned only after they show up in two separate takes, and near-misses of words Bolo already knows (BoloM next to Bolo, KBHRMS next to KVHRMS, DDeveloper) are never learned.
- The log now says verified=unreadable, with the reason, when Bolo had to type into an app whose text it can't read back, instead of a bare "unconfirmed".
