# Bolo 0.1.21

Accuracy and silence handling after the 0.1.20 field tests.

## What's new

- Default speech model is now Whisper Large v3 for clearer English and mixed Urdu/English.
- Silent holds and key-clicks no longer paste invented phrases like "thank you" or "sorry".
- A long quiet hold with a short phrase at the end no longer invents the wrong sentence from room noise.
- Live preview and the final paste use the same model and vocabulary path.
- Window context (Cursor, Gmail, open file names) helps spell product and file terms.
- The overlay reports Inserted instead of Typed after a successful paste.
