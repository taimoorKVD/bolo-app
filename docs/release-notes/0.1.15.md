# Bolo 0.1.15

The black flash on each take is gone, and a failed online request is recorded and tried again.

## Dictation

- The on-device speech program no longer opens a black console window.
- The listening bubble stays transparent when it appears.
- If the online service cannot take a request, Bolo writes the reason to the log (never the key) and tries again on the next take instead of staying on the PC model for the rest of the session.
- A transcript that already came back is still inserted. If a take really cannot be transcribed, Bolo says "Couldn't catch that, please try again."
