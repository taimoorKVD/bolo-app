How it works

Three beats. No waiting screen.

  1. Hold

    Press and hold the hotkey (default Ctrl+Win). The compact listener appears and stays with you while you talk.

  2. Speak

    Talk naturally — English, Urdu, Roman Urdu, or a mix. When you release, the character picks up a pen and writes.

  3. Paste

    Clean text lands at the caret. The overlay ducks away with a soft chime. No labels, no Groq branding in the UI.

Features

Built for the focused field

Animated listener

A soft, friendly character listens with glowing ear rings, then writes with a tiny gold pen — the same overlay that ships in the app.

Instant push-to-talk

The mic stays warm, so the first press shows the listener immediately. No “Starting…” delay.

Any language in, English out

Speak Urdu or mix languages; Bolo can translate into clean English, or keep the language you spoke.

Works where you type

Word, browsers, Slack, mail, terminals — wherever the caret is. Tray app, global hotkey, optional dictionary and history.

Long takes stay quick

Longer speech is cut on pauses and transcribed while you keep talking, so release still feels snappy.

Your key, or ours

Ships ready to dictate with a built-in Groq key. Add your own in Settings anytime; it stays in Windows Credential Manager.

Privacy

Audio goes to Groq. Nothing sits on a Bolo server.

Each take is uploaded to Groq for transcription (and optional cleanup). Bolo does not run its own backend for your audio, and it does not collect telemetry.

What leaves the PC

  • Audio for the current take, as 16 kHz mono FLAC (or WAV)
  • Optional short cleanup requests to Groq when that setting is on

What stays local

  • Settings, dictionary, and history on this PC
  • Your Groq API key in Windows Credential Manager
  • No Bolo account and no Bolo analytics

FAQ

Before you install

SmartScreen says Windows protected your PC

The installer is unsigned. SmartScreen will say it prevented an unrecognized app from starting. Choose More info, then Run anyway. That warning is expected until the binary is signed.

Do I need a Groq API key?

No. Bolo can dictate with its built-in Groq key. Add your own at console.groq.com/keys if you want requests on your account. Your key is stored in Windows Credential Manager on this PC. It is not written into the settings file and it is not logged.

Is there a free tier?

Bolo does not charge a subscription and does not run a server of its own. The built-in key follows Groq's limits for that key. If those limits are hit, add your own Groq API key in Settings.

What does the PC need?

Windows 10 or 11, 64-bit. Windows 11 already includes the WebView2 runtime. On Windows 10 the installer can fetch it. The setup is per-user and does not need an administrator account. A microphone is required. An elevated window, such as a terminal opened as Administrator, will not receive dictation.

What is the little character on screen?

That is the listening overlay. It loops a soft listen animation while you hold the hotkey, switches to a writing loop while Bolo transcribes, then hides with a gentle chime when the text is pasted.
